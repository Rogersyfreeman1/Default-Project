# Lassy AdCraft Studio

Professional Video Generator for Social Media Ads

## Quick Start (2 Steps)

### Step 1: Double-click "Start AdStudio.bat"
This will install all required packages and start the program.

### Step 2: Follow the menu
- Choose option 1 to create a video from images
- Choose option 2 to create a text-only video
- Choose option 5 to connect your Shopify store

---

## Features

### Video Creation
- Create videos from images with text overlays
- Text-only animated videos
- 10+ ad templates (Sale, Black Friday, Product Launch, etc.)
- Transitions: fade, slide, zoom, dissolve
- Text animations: fade, bounce, typewriter

### Shopify Integration
- Connect your Shopify store
- Auto-pull product images and prices
- Create product promo videos automatically
- Sale/promo videos with discount badges

### Music Manager
- Add your own music files
- Preview music before using
- Organize by style/category
- Free royalty-free music sources

## How to Connect Shopify

1. Go to your Shopify Admin
2. Settings → Apps and sales channels
3. Develop apps → Create an app
4. Configure Admin API scopes
5. Install app → Copy access token
6. Open Lassy AdCraft Studio
7. Select option 5 → Setup Store Connection
8. Enter your store URL and access token

## Need Help?

If you get an error:
1. Make sure Python is installed
2. Make sure FFmpeg is installed
3. Try running "Start AdStudio.bat" as administrator
4. Check that your images are in a valid format (JPG, PNG)
