## What I do
- Review identity protection configuration
- Analyze identity alerts and threats
- Suggest improvements to protection settings
- Generate identity security reports
- Check for exposed personal information

## When to use me
Use this skill when you want to review or improve identity protection settings.
I will analyze the identity_config.json and identity_alerts.json files to provide insights.

## How to use
1. Load this skill when prompted
2. I will read the current configuration
3. Analyze any alerts or threats
4. Provide recommendations for improved protection
5. Generate a summary report if needed
