## What I do
- Analyze Python files for security vulnerabilities
- Check for hardcoded credentials or API keys
- Identify insecure file operations
- Detect command injection risks
- Review configuration files for sensitive data
- Generate security reports

## When to use me
Use this skill when you want to perform a security audit of the codebase.
I will scan all Python files and configuration files, then provide a detailed report of any security issues found.

## How to use
1. Load this skill when prompted
2. I will analyze the codebase systematically
3. Provide findings with severity levels (Critical, High, Medium, Low)
4. Suggest specific fixes for each issue
